    Para executar o código da StarRobux é necessário garantir que está no devido
diretório (pasta raiz do projeto) e, então, executar o comando indicado abaixo:

- "npx tsx .\src\api.ts"

## Adendo sobre a Inteligencia Artificial:

O chat bot utiliza uma API do Groq, onde tem seu acesso **limitado** e responde as perguntas que não são previamente respondidas pelo sistema. As respostas prontas junto da API pode ser encontrado em "bot.ts"

## Utilização de IA para o código:

Devido a estarmos no inicio do aprendizado de Backend e com uma boa base de HTML + CSS, foi utilizado IA para auxilar na construção do código do backend, para aprendermos de maneira correta como utilizar os gets, listenenrs e etc.
A parte do "Frontend" foi feita sem uso de Inteligência Artificial no inicio, sendo apenas utilizada na parte da integração com o backend e pesquisa para uso de efeitos e estilização.

## Instalações necessárias:

- npm install express
Utilizado para a integração do html

- npm install groq-sdk@latest
Necessário para o chatbot conseguir responder com sua base de Inteligência Artifical da API
